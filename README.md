# Maintainly

Maintainly is a React operations dashboard inspired by modern facilities-maintenance tools.

## Run locally

```bash
npm install
npm run dev
```

## Current scope

- Dashboard overview and team activity
- Work-order list with status filters
- Asset inventory
- Preventive-maintenance schedules
- Responsive application shell and reusable UI primitives

The app currently uses local mock data. Backend persistence, authentication, attachments, and real-time updates can be added as the core workflows are finalized.
